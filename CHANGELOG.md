# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-20
### Added
- **System Health Checks**: Live DB connections ping tests and health report pages.
- **Security Audit Trails**: DB-backed logging of all auth events, metrics, and configurations.
- **Interactive Flags**: Admin UI switch toggles to disable or enable system gates dynamically.
- **Intelligent Document Assistant**: Explainer paragraph summarizer, revision quiz engines, ATS resume matcher, actions checklist scan, and markdown exports.
- **Enhanced Coach Evaluator**: STAR methodology validation, strength/weakness cards, custom study roadmaps, and portfolio project suggestions.

### Changed
- Decoupled RAG pipeline, knowledge graphs, and LLM orchestration models.
- Routed dashboard telemetry to use dynamic database aggregation pipelines.

## [0.9.0] - 2026-07-15
### Added
- Structured retrieval models, cache modules, and search rerank indexes.
- Speech transcription handlers.
