# Contributing to AI Career Assistant

Thank you for your interest in contributing to AI Career Assistant! We welcome help in making the platform more performant, robust, and accessible.

## Development Workflow

### 1. Requirements & Tools
- Ensure Python 3.10+ and Node.js 18+ are installed.
- Ensure Docker is set up if running integration setups.
- Use `pytest` for backend unit checks and `npm run build` for frontend typescript checks.

### 2. Code Style
- **Python**: Follow PEP 8 guidelines. Maintain docstrings on services.
- **TypeScript/React**: Leverage TS Interfaces and custom styling systems. Maintain responsive layouts.

### 3. Pull Request Standards
- Write clean commits explaining features or refactoring.
- Run both backend test suites and frontend compiles before proposing commits.
- Detail the manual verification process in description fields.
